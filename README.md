# Triangle-Shape-Detector
This project takes three sides of a triangle as input and determines whether the triangle is Equilateral, Isosceles, Scalene, or Acute.
It is written in Java and demonstrates how conditional logic and debugging can be used to detect errors and verify program correctness.

🧩 Features

Accepts three integer values representing triangle sides.

Validates whether the input forms a proper triangle.

Classifies the triangle as:

Equilateral (all sides equal)

Isosceles (two sides equal)

Scalene (no sides equal)

Acute (all angles less than 90°)
